# Lavanya Job Portal

A responsive, multi-page frontend job portal demo built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home
- `jobs.html` — Search and filter jobs
- `job-details.html` — Job information and demo apply/save actions
- `companies.html` — Employer directory
- `login.html` — Demo login form
- `register.html` — Demo registration form
- `dashboard.html` — Saved jobs, applications and resume picker
- `contact.html` — Contact form demo

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Notes
- Job data is sample content.
- Saved jobs and demo applications use browser `localStorage`.
- Login, registration, contact submission and resume selection are frontend demonstrations only. A real deployment needs a secure backend, database, authentication and file storage.
- Images load from Unsplash and Google Fonts load from Google Fonts, so an internet connection is needed for those assets.
